# Chattie - a simple chat app using websockets
## Prerequisities
- Node (I use v24.19.0)
- npm
- Packages installed with npm i
## Deploying
1. Edit the URLs at static/chat.html and chatserver.js. Currently they are 127.0.0.1 (localhost).
2. Run "npm i".
3. Start the server.
 - Run "node index.js" to start the server.
 - Run "node chatserver.js" to start the websocket.
